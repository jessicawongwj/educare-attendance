Admin Access

Admin accounts have access to all tabs, all trainers' data, and all management functions. Trainer accounts see only their own class. Access is controlled by Microsoft 365 login email.

Adding a new admin

  1. Go to Settings → Admin Access sub-tab.
  2. Type the person's Microsoft 365 work email in the input field.
  3. Click Add Admin. The email is written to the database immediately.
  4. The person gains admin access on their next login — they don't need to log out and back in if already in the portal.

Removing an admin

In the Admin Access sub-tab, find the email in the list and click Remove. The change takes effect on their next login.

Do not remove your own email from the admin list — you will lose access and will need a developer to restore it directly in the database.
Trainer access is configured separately in the Trainer Schedule — admins are a different list from trainers.
Dashboard

The Dashboard tab is the top-level overview. Only admins can see it. It shows live attendance statistics grouped by campus and trainer.

Campus tabs

Tabs at the top of the dashboard filter by campus: 316 Adelaide St (Brisbane CBD), Gold Coast (Southport), and Woolloongabba Studio. The default view shows all campuses.

Trainer breakdown cards

Each trainer with enrolled students gets a card showing their name, course(s), attendance rate, and student count. Cards are grouped per campus.

  • A TODAY badge shows trainers who have a scheduled class today
  • Cards that are faded / greyed out indicate the trainer has no class scheduled for the selected day
  • Click the student count on a trainer card to open that trainer's student list

Dashboard periods

Toggle between Today, This Week, and This Month to change the attendance figures shown across all cards.

At-Risk students

Students with an overall attendance rate below 80% are flagged At Risk. The count is shown on each trainer card and in the campus summary bar.

The Dashboard only shows active students. Withdrawn, completed, and not-started students are excluded from all counts.
Daily Attendance

The Daily Attendance tab shows all QR check-ins across all trainers for a selected date.

Filtering the roll

  • Date picker — view any past date
  • Campus tabs — filter by campus
  • Trainer dropdown — narrow to one trainer's students
  • Search box — find a student by name or ID
  • Status filter — show Present, Absent, or All

Manually marking attendance

Admins can mark any student present or absent for any date. See Managing Students for full steps.

Bulk select

Click Bulk Select to tick multiple students and mark them all present or absent at once — useful for days where most of a class attended but didn't scan.

Rate Check

The Rate Check tab shows attendance percentages for every student across all trainers. Admins can filter by campus, trainer, and status.

Filtering

  • Campus filter — view one campus at a time
  • Trainer filter — narrow to a specific trainer

Print Class List

Click Print Class List at the top of Rate Check to generate a printable register grouped by trainer course, with columns: #, Name, Student ID, Campus, Commenced, Signature. Use the trainer dropdown first to scope the printout to one trainer if needed.

Click any student's name to open their full attendance history — all check-in dates from commencement are shown.
My Class

The My Class tab shows enrolled students grouped by course. Admins see all students and can use the trainer filter to view one trainer at a time.

Course filter pills

Pills at the top represent each course (showing the course code). Click a pill to filter to that course only. Useful when a trainer runs multiple courses with the same short name.

Sub-tabs

  • Not Checked In — active students who haven't scanned today
  • Tentative — newly enrolled students who have never attended

+ Attendance button (inline attendance entry)

Every student row has a green + Attendance button below the Remove button. Trainers and admins can use this to record attendance without opening any modal:

Single date

Pick any date (defaults to today), set status to Present or Absent, add an optional note, and click Save. The record writes to the database immediately.

Date range

Fill both the Date and To fields to mark a whole range in one save. Weekends are automatically excluded — only weekday records are created.

Quick-note chips appear below the note field for common reasons: Placement, Medical Certificate, Personal, Absent — No Contact, Late Arrival. Click a chip to pre-fill the note field.

Placement weeks are best recorded with the date range + "Placement" note — one click marks the full week with a clear audit trail.
All records saved via + Attendance appear in the student's attendance history, Rate Check, and all exports exactly as if the student had scanned the QR code.
Not Started Tab

The Not Started tab is admin-only. It shows students whose enrollment status is not-started — enrolled but not yet commenced.

Tentative students

Students who have been added to the roster but have never attended appear in the Tentative sub-tab. Once they scan the QR code for the first time, they automatically become active and move into the daily roll.

Manually activating a student

  1. Go to Not Started → Tentative sub-tab.
  2. Find the student and click Mark Active.
  3. Their status changes to active and they immediately appear in the daily roll.
Use Mark Active when a student has physically commenced but hasn't had a chance to scan the QR code yet — for example, students in a first session where the QR wasn't available.
Managing Students

Enroll a single student

  1. Click the + Enroll Student button (top of any student list view).
  2. Fill in: Student ID, Full Name, Course, Course Code, Trainer, Campus, Commencement Date, Expected End Date.
  3. Click Save. The student appears in the roster immediately.
The Student ID must match exactly what's in your TMS (e.g. Axcelerate). If the ID already exists in the system with the same course, the enrollment is updated rather than duplicated.

Bulk enroll from CSV (Roster Upload)

  1. Go to Settings → Roster sub-tab.
  2. Prepare a CSV with columns: id, name, course, courseCode, trainer, campus, commenced, expectedEnd, status.
  3. Click Choose File, select your CSV, then click Upload Roster.
  4. A preview shows the records to be imported. Click Confirm Import.
  5. All students are upserted — existing enrollments are updated, new ones are inserted.

Update a student's start date

  1. Click the student's name to open their history modal.
  2. Click Edit Start Date.
  3. Enter the correct commencement date and save. The attendance rate recalculates immediately.

Reassign a student to a different trainer

Go to Settings → Trainer Schedule → use the Reassign Trainer section. Select the current trainer, the new trainer, and optionally a specific course code. All matching enrollments and attendance records are updated.

Withdrawing a Student

Withdrawing removes a student from the active roll. All attendance history is preserved — no records are deleted.

How to withdraw a student

  1. Click the student's name anywhere in the portal to open their history modal.
  2. Click Withdraw Student or Change Status.
  3. Select a reason from the dropdown:

Settings Tab

The Settings tab is admin-only and contains five sub-tabs. All changes write to the database immediately.

Trainer Schedule

View and edit the trainer-to-campus-to-course-to-day mapping. Used to determine which trainers have class on which days and to power the Dashboard cards.

Email Reports

Configure report recipients and manually trigger fortnightly, monthly, or absence alert emails.

QR Code

View, download, and print the QR code for each campus check-in page.

Roster

Upload a CSV to bulk-enroll or update students. Also use this to view and manage the current enrollment list.

Admin Access

Add or remove admin email addresses. Changes take effect on the user's next login.

Trainer Schedule sub-tab

The Trainer Schedule maps each trainer to their campus, their courses, and which days of the week they run each course (Mon=0 through Fri=4). This is what the Dashboard uses to show the TODAY badge and grey out cards when a trainer has no class.

To modify the schedule, edit the table in the Settings Trainer Schedule view and click Save Schedule. Changes are written to the database and take effect immediately for all users.

If a trainer's name in the Trainer Schedule doesn't exactly match their name in the student enrollment records, their students won't be linked to their dashboard card. Names must match exactly (including capitalisation).
Email Reports

Three automated reports are sent from the Educare shared mailbox to configured recipients.

Report typeContentAuto-sends
Fortnightly Attendance % per trainer for the last 14 days, with at-risk student list 1st and 15th of each month at 8 am AEST
Monthly Attendance % per trainer for the current calendar month 1st of each month at 8 am AEST
Absence Alert Students with no attendance recorded in the last 14 days 1st and 15th of each month at 8 am AEST

Manually trigger a report

  1. Go to Settings → Email Reports.
  2. Click the button for the report type you need (Send Fortnightly, Send Monthly, or Send Absence Alert).
  3. The report generates and emails all configured recipients within a minute.

Update report recipients

  1. Go to Settings → Email Reports.
  2. Edit the recipient email list (one per line or comma-separated).
  3. Click Save Recipients.
Colour coding in email reports: green ≥ 90%, amber 80–89%, red < 80%.
QR Code Check-In

Students check in by scanning the QR code poster displayed at each campus entrance. No app download is required — the QR code opens a browser page.

How students check in

  1. Student scans the QR code with their phone camera.
  2. A browser page opens (the Educare check-in page). No login needed.
  3. Student enters their Student ID, selects their trainer and course from the dropdowns.
  4. Ticks the attendance declaration and taps Check In.
  5. Their GPS location is verified to confirm they are at the campus.
  6. A confirmation screen is shown. The record appears in the admin portal immediately.

Printing and displaying the QR code

  1. Go to Settings → QR Code.
  2. Click Download to save as a PNG image, or Print to send directly to a printer.
  3. Print A4 or larger, laminate, and display at each campus entrance.
The same QR code works for all campuses — campus is determined by the student's GPS location at check-in time.
If a student scans from outside the campus geofence (e.g. from home or a car park), check-in is blocked. They must be manually marked present by their trainer or admin.
Holidays

The Holidays tab shows Queensland public holidays and Educare's scheduled school breaks for the year, visible to both trainers and admins. It's read-only reference — there's no edit UI on this tab.

What's shown

  • Public Holidays — every Queensland public holiday, split into Upcoming and Past, with the next one highlighted at the top of the tab
  • School Breaks — the term-break periods from the Educare Academic Calendar (Easter, mid-year, spring, year-end), with the current break flagged NOW if one is in progress

Both lists feed directly into attendance rate calculations — public holidays and school-break days are excluded from every student's expected-sessions denominator, in the portal and in the automated email reports.

Updating for a new year

These dates are not editable from Settings — they're defined in the portal's code (PUBLIC_HOLIDAYS and SCHOOL_BREAKS in educare-portal.html, and the equivalent calendar logic in api/_calendar.js used by the dashboard and email reports). A developer needs to update both places and redeploy at the start of each academic year, once the next year's Educare Academic Calendar and the QLD public holiday list are confirmed.

If the Holidays tab and a student's attendance rate ever disagree about whether a date counts as a holiday, it means the two data sources have drifted — flag it to a developer rather than adjusting either by hand.

Attendance rate formula

Rate = sessions attended ÷ expected sessions × 100

Expected sessions are calculated from the student's commencement date to today. The academic calendar excludes weekends, Queensland public holidays, and school-term breaks. All calculation is from commencement date — there is no rolling window cap.
